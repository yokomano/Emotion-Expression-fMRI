## Data and code resources

The complete de-identified BIDS dataset is available through OpenNeuro:

- OpenNeuro dataset: https://openneuro.org/datasets/ds008583

This GitHub repository contains the analysis and figure-generation code.
Participant-level imaging, behavioral, post-scan rating, self-construal, and
TAS-20 data are maintained in OpenNeuro rather than duplicated here.

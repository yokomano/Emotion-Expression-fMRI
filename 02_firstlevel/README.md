# First-level Analysis

This directory will contain the SPM first-level analysis scripts associated
with Mano et al. (2026).

## Status

Documentation and code review are currently in progress.

## Planned contents

- Main first-level GLM
- Exploratory context × response GLM
- Contrast specification
- Batch execution script

## Purpose

`firstlevel_context_no_yes_v1_0.m` specifies and estimates an exploratory
SPM first-level model in which the emotion-expression decision phase is
divided into:

- `No_relational`
- `Yes_relational`
- `No_individual`
- `Yes_individual`

The sentence phase is modeled separately as `Emo_Sentence` and
`Ctrl_Sentence`. Missed emotion trials are modeled as `Question_Miss`.

## Main changes from the laboratory working script

1. All machine-specific paths were moved into a configuration structure.
2. Participant IDs can be supplied explicitly through `cfg.subList` and
   `cfg.emList`.
3. Required files, directories, table columns, event values, and motion
   parameters are validated before SPM estimation.
4. Context labels are checked for completeness, duplication, and allowed
   values.
5. Existing `SPM.mat` files are protected unless `cfg.overwrite=true`.
6. Trial counts are printed for every run.
7. The complete configuration is saved in each participant output folder.
8. Deprecated `dlmwrite` was replaced by `writematrix`.
9. Error identifiers were added to support reproducible troubleshooting.
10. Personal usernames and local directories are absent from the public code.

## Example

```matlab
cfg = struct();

cfg.rootDir = 'D:\MRI_data_new';
cfg.behRoot = 'D:\behavioral_results';
cfg.contextFile = fullfile( ...
    cfg.behRoot, ...
    'scenario_context_classification_96_utf8bom.csv');

cfg.spmDir = 'C:\MATLAB_Toolboxes\spm';

% Supply the true mapping when participant IDs are not strictly sequential.
cfg.subList = {'sub-001', 'sub-002'};
cfg.emList  = {'em0001',  'em0002'};

firstlevel_context_no_yes_v1_0(1, cfg);
```

## Scientific assumptions retained from the original script

- Four runs per participant.
- TR = 0.8 s.
- Canonical HRF without temporal or dispersion derivatives.
- High-pass filter = 128 s.
- AR(1) serial-correlation model.
- Six rigid-body motion parameters.
- Decision-event duration equals the primary reaction time.
- Miss duration is fixed at 2 s.
- Only valid emotion trials enter the four context × response regressors.
- Sentence regressors include all emotion and control sentence presentations.

These assumptions should be checked against the manuscript Methods and the
final analysis record before public release.

## Important verification items before GitHub release

### Participant mapping

The original script assumes a one-to-one sequential mapping:

```text
sub-001 ↔ em0001
...
sub-046 ↔ em0046
```

This must be verified. A private participant-key file must not be uploaded to
GitHub.

### Empty conditions

Some runs may contain zero events in one of the four decision cells. The
script preserves all seven named conditions. Before release, confirm that the
installed SPM version handles empty onset vectors as intended and that the
resulting design matrices and contrast vectors remain consistent.

### Image filename

The default image pattern includes a laboratory-specific `s6tmp_` prefix.
Replace it with the final preprocessing filename convention or document the
origin of this prefix.

### Smoothing and preprocessing provenance

The script consumes images that appear to have already been smoothed and
preprocessed. The repository should state:

- the software and version used,
- the smoothing kernel corresponding to `s6`,
- whether fMRIPrep outputs were modified after preprocessing,
- the exact spatial template,
- and the command or script that produced the analysis input image.

### Confounds

Only the six motion parameters are included. Confirm that this matches the
reported Methods. Framewise displacement, outlier regressors, physiological
regressors, and censoring are not included in this model.

### Contrasts

This file specifies and estimates the model only. Contrast creation must be
provided in a separate version-controlled script. Contrast weights should be
generated by regressor name rather than by manually assumed column positions.

### Exploratory status

The file header identifies this as an exploratory model. The README for the
full repository should distinguish confirmatory analyses from exploratory
analyses and identify which manuscript or supplementary results, if any, use
this model.

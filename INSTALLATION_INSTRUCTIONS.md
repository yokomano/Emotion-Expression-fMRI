# Installation Instructions

Copy these files into the existing repository.

## Repository root
- `CITATION.cff`
- `requirements.txt`

Merge the contents of `README_SECTION_TO_ADD.md` into the existing top-level
`README.md`.

## Existing folders
- Copy `04_roi/roi_coordinates.csv`
- Copy `04_roi/README_ROI_COORDINATES.md`
- Merge `05_behavior/README.md` with the existing README if necessary

## New folder
Copy the complete `07_documentation/` directory to the repository root.

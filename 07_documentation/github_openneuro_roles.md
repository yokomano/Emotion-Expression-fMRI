# GitHub and OpenNeuro Resource Division

## GitHub
The GitHub repository contains analysis code and documentation:

- MATLAB analysis scripts
- Python data-preparation scripts
- R model specifications
- ROI definitions
- Figure-generation scripts
- Software and workflow documentation

## OpenNeuro
The complete de-identified dataset is hosted at:

https://openneuro.org/datasets/ds008583

It contains MRI data, event files, stimulus information, participant metadata,
post-scan ratings, self-construal scores, and TAS-20 scores.

## Reproduction workflow
1. Obtain the data from OpenNeuro.
2. Use the GitHub preprocessing and first-level scripts.
3. Run group-level analyses and ROI extraction.
4. Generate the manuscript figures.

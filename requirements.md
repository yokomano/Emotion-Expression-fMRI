# Software Requirements

## MRI and MATLAB analyses

- MATLAB R2024a
- SPM25
- fMRIPrep 23.2.1
- Nipype 1.8.6

## Python

- Python 3.10 or later
- pandas
- numpy

## R

- R 4.x
- lme4
- lmerTest
- readr
- dplyr

## Operating system

The original local scripts were developed on Windows. Public scripts use
editable path settings and may be adapted to other operating systems.

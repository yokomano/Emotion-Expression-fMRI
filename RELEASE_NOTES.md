# Release Notes

## v1.0.0-rc1

Initial public release candidate accompanying the SCAN publication.

### This release includes

- MATLAB preprocessing utilities and documentation
- First-level SPM analysis scripts and contrast generation
- Second-level random-effects analyses
- ROI extraction scripts (right TPJ and right dlPFC)
- Behavioral data preparation and GLMM analysis templates
- Figure-generation scripts corresponding to Figures 3 and 4
- OpenNeuro phenotype generation scripts
- Manuscript-to-code mapping and reproducibility documentation

### Associated dataset

The accompanying de-identified imaging and behavioral dataset is available through **OpenNeuro**:

> https://openneuro.org/datasets/ds008583

### Release status

This release candidate will be verified against the archived analysis environment before the final **v1.0.0** release.
